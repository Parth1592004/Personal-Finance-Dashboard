# Personal Finance Dashboard

## Overview

This project is an interactive Personal Finance Dashboard built using Power BI and Excel.

The dashboard helps users:

* Track income and expenses
* Analyze spending patterns
* Monitor savings
* Visualize financial trends
* Calculate EMI payments
* Estimate SIP investment returns

## Tools Used

* Power BI
* Excel
* DAX

## Features

### Dashboard Page

* Total Income KPI
* Total Expenses KPI
* Savings KPI
* Savings Percentage
* Monthly Income Trend
* Monthly Expense Trend
* Expense Category Breakdown
* Income vs Expense Analysis

### Financial Planning Page

* EMI Calculator
* SIP Future Value Calculator
* Total Invested Amount
* Wealth Gain Estimation

## Project Screenshots

Dashboard and financial planning screenshots are available in the screenshots folder.
